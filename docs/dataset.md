# Dataset source

## UCI Online Retail

- Source: https://archive.ics.uci.edu/dataset/352/online-retail
- Creator: Daqing Chen
- Citation: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Coverage: transactions from 1 December 2010 through 9 December 2011
- Local file: `data/raw/Online Retail.xlsx`

The dataset contains invoice, product, quantity, invoice date, unit price, customer, and country fields. Cancellation invoices are marked with an invoice number starting with `C`. We will preserve the source file and build cleaned outputs separately.
